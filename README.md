# Srikanth & Shreya — Wedding Website

A responsive, static wedding invitation website built from the details in the supplied PDF.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example, `srikanth-shreya-wedding`).
2. Upload the contents of this ZIP to the repository root (make sure `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish and open the URL shown in the Pages settings.

## Included
- `index.html` — wedding invitation page
- `style.css` — responsive styling
- `script.js` — live countdown to the wedding muhurtham
- `assets/` — invitation page images and original PDF
